# Open-Source Components

The foundation intentionally keeps third-party code small.

## Application libraries

- Astro — MIT
- `@astrojs/mdx` — Astro project integration
- `@astrojs/sitemap` — Astro project integration
- `@astrojs/rss` — Astro project helper
- Pagefind — MIT
- Fontsource repository/tooling — open source

## Fonts

- Newsreader — SIL Open Font License 1.1
- Bricolage Grotesque — use through Fontsource; verify the bundled font package license during
  dependency installation and preserve its notices.

Do not copy code or visual assets from Financial Times. FT is a product/UX reference only.

Before production, the package lockfile is the authoritative list of installed dependencies and
their versions; preserve applicable notices.
