# SECOND / PASS / BRIEF — Summary

## Summary
Running an AI model yourself replaces a managed API bill with capacity, utilization risk and operations. In a same-model Mistral Small 4 control, an illustrative 10k-input/1k-output task costs $0.0021 on Mistral's managed API. One AWS Mumbai 8×H100 Capacity Block is $27,564.80 for a 730-hour month, putting the price-only break-even near 13.13 million tasks. But that boundary is provisional: at 80% effective utilization the fleet would need to serve about 22,476 useful tasks/hour under the required SLO.

## Key finding
**13.13M tasks/month — price boundary, not throughput proof.**
