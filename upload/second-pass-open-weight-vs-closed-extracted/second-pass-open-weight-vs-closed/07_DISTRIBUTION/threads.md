# Threads

Running your own model removes the API bill. It replaces it with another bill.

In one same-model Mistral Small 4 scenario, the API is 0.21¢ per 10k-input/1k-output task. An 8×H100 capacity reservation is $27,564.80 for the month. The price lines cross around 13.13M tasks.

But price is only half the question: can the GPUs actually serve that load, at the latency you need, while staying usefully busy?
