# Financial Times Inspiration — Principles, Not Imitation

Reference: https://www.ft.com/

SECOND / PASS should borrow the editorial discipline of a world-class newspaper without copying
Financial Times branding, proprietary design assets, page composition, typography, or color.

## Principles to absorb

### 1. Dense information hierarchy
A homepage can show many stories without feeling chaotic when hierarchy is controlled through
type scale, rules, spacing, grouping, and editorial priority.

### 2. Clear editorial modules
Lead story, top stories, editor-selected work, most-read/most-useful modules, opinion/analysis, data,
and topic sections each have clear visual ownership.

### 3. Metadata supports trust
Timestamps, section labels, author names, exclusivity/format labels, and update state should be easy
to scan without dominating the story.

### 4. Repetition creates orientation
Consistent section headings, rules, metadata positions, and story anatomy help users scan quickly.

### 5. Serious typography
The page should feel authoritative because of typography and hierarchy, not decorative UI chrome.

### 6. Mobile is editorially selective
Desktop density should not simply collapse into a tiny grid. On smaller screens, preserve story
priority while removing nonessential secondary detail.

## SECOND / PASS divergence

- no FT salmon/pink imitation;
- no FT logo/masthead imitation;
- unique Bricolage Grotesque + Newsreader system;
- slash as a structural signal;
- FIRST PASS / SECOND PASS article anatomy;
- evidence panels and change logs;
- source-backed technical data as a first-class product;
- deliberately low ad density;
- stronger technical table/mobile handling;
- static-first zero-framework-JS architecture.
