# Advertising System

## Principle
Advertising is subordinate to reading.

Optimize reader lifetime value, return rate, newsletter conversion, and premium audience quality
rather than maximum ad impressions.

## Commercial priority
1. direct sponsorship
2. data-product sponsorship
3. newsletter sponsorship
4. premium display
5. programmatic fallback

## Never
- popups
- prestitials/interstitials
- sticky bottom ads
- sticky video
- autoplay sound
- ads covering navigation
- ads between headline and FIRST PASS
- ads inside tables/code
- ads between chart and explanation
- ads styled like editorial

## Density
Under 700 words: 0 inline.
700–1,800: max 1.
1,800+: max 2.
Optional end sponsor unit.

These are ceilings.

## Placement
Use explicit `<AdBreak />` at editorially natural section boundaries.

## Homepage
No above-fold ad. Max two display breaks in main flow.

## Data
Prefer one sponsor for the whole tool instead of interrupting the table.

## Stability
Reserve responsive geometry for real ad units.
When no paid creative exists, use a useful house unit (`/ BRIEF`, `/ DATA`, strong article).

## Labels
Programmatic: `ADVERTISEMENT`.
Direct: `SUPPORTED BY`.
Sponsored editorial: unambiguous dedicated label/template.
