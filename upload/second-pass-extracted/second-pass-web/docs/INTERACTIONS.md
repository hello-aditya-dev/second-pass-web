# Interaction System

Interaction exists to improve comprehension or navigation.

## Evidence
Use native `<details>` whenever possible.
Desktop may align it to a rail; tablet/mobile inline.

## Reading progress
A 1–2px line at top of long articles. No gamified percentage badge.

## Tables
Future compare tables may offer `All / Changes only` with tiny vanilla JS.

## Search
Pagefind powers custom search. No hosted search bill.

## Navigation
Horizontal topic strip on mobile/tablet. No marquee.

## Motion
100–160ms state changes.
No page entrance choreography.
No scroll hijacking.
Honor reduced motion.
