## / SECOND PASS

A clean price table is attractive because every model appears comparable. That appearance can be
misleading.

Cached input, batch pricing, output length, retries, tool calls, latency objectives, context reuse,
and provider billing semantics all affect real cost. A useful price database therefore has to
store more than two numbers.

## The data product matters

SECOND / PASS should eventually preserve effective date, pricing conditions, source URL, model
version, and historical records. That lets an old analysis remain historically coherent rather
than silently inheriting today's prices.

This page contains no live provider price.
