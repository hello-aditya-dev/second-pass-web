## / SECOND PASS

Security reporting becomes misleading when distinct states are compressed into a phrase such as
"actively exploited."

A good article distinguishes the vendor advisory, vulnerability identifier, affected version,
severity assessment, exploit availability, observed exploitation, and mitigation status.

This demo page contains no live vulnerability advisory.
