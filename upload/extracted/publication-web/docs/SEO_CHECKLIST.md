# SEO / News Foundation Checklist

## Per article

- [ ] unique indexable URL
- [ ] canonical
- [ ] descriptive title
- [ ] useful meta description
- [ ] exactly one clear H1
- [ ] real author
- [ ] publication date
- [ ] truthful modification date
- [ ] appropriate Article/NewsArticle schema
- [ ] high-resolution lead image when available
- [ ] image alt text
- [ ] internal links where useful
- [ ] source/correction presentation
- [ ] no fake updated date

## Site

- [x] robots route
- [x] sitemap route
- [x] metadata base configuration
- [x] manifest
- [ ] RSS/Atom
- [ ] news sitemap after real publishing cadence begins
- [ ] Search Console setup after domain
- [ ] analytics after provider decision
- [ ] author profile routes before multiple authors
- [ ] image pipeline

## Rule

Do not generate low-value pages simply to capture query variations.
