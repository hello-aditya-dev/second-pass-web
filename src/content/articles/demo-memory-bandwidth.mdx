## / SECOND PASS

A technical product is easy to market with one giant number. A deployed system is harder.

An accelerator can add arithmetic throughput while a workload remains constrained by memory
capacity, memory bandwidth, communication, utilization, software maturity, or request shape.
That makes the first useful question less dramatic: **what was limiting the previous system?**

The second question is whether the new architecture actually changes that constraint.

<div class="table-wrap">

| Question | Weak first-pass coverage | SECOND / PASS standard |
| --- | --- | --- |
| Performance | Repeat peak figure | Match metric to workload |
| Benchmark | Quote a ratio | Preserve test conditions |
| Cost | Use sticker price | State utilization and operating assumptions |
| Conclusion | Declare a winner | Preserve constraints and uncertainty |

</div>

## Evidence determines the headline

If the evidence supports only a narrow conclusion, the headline should become narrower. Research
should shape the story; the story should not force the research into a predetermined claim.

This is demo content. It does not assert any current GPU specification.
