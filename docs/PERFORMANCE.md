# Performance Budget

Performance is product design.

Internal ambitions at the 75th percentile when measured:
- LCP < 1.5s
- INP < 100ms
- CLS < 0.05

Do not claim these until measured.

Launch:
- static output
- no client framework bundle
- no video
- no third-party analytics yet
- no ad script yet
- self-host fonts
- minimal vanilla JS
- explicit media dimensions

Add one commercial/analytics vendor at a time and measure the regression.
